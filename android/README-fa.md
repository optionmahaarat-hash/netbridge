# NetBridge برای اندروید

اپ بومی (Kotlin + Jetpack Compose) با تم مشکی-طلایی. همان منطق نسخه ویندوز:
- کانفیگ‌های اپ (۱۰۴ سرور) داخل برنامه است و بار اول خودکار بالا می‌آید.
- دکمهٔ بزرگ طلایی = **AUTO**: هر سرور × هر روش bypass (off / PattNG / standard / ECH) در یک Xray خصوصی با درخواست واقعی به یوتیوب، اینستاگرام و گوگل تست می‌شود؛ روش برنده در سرور ذخیره می‌شود و به ۴ سرور برتر (با Balancer) وصل می‌شود.
- «＋ افزودن کانفیگ»: لینک vless/vmess/trojan/ss، لیست base64 یا لینک اشتراک. اگر لینک کپی‌شده در کلیپ‌بورد باشد، خود برنامه پیشنهاد افزودن می‌دهد.
- سایت‌های ایرانی مستقیم (قابل خاموش‌کردن)، فارسی/انگلیسی، گزارش برای پشتیبانی.

## ساخت APK (بدون Android Studio)
1. پوشهٔ پروژه را در یک مخزن **GitHub** (خصوصی) بگذارید.
2. GitHub ← Actions ← **build-android** ← Run workflow (حدود ۱۰ دقیقه).
3. از بخش Artifacts فایل **NetBridge.apk** را بگیرید و به خانواده بدهید (نصب از فایل؛ اندروید ۸ به بالا، فقط arm64 = تقریباً همهٔ گوشی‌های امروزی).
4. **`signing-key-KEEP-SAFE`** (فایل release.jks) را هم دانلود و نگه دارید، و محتوای base64 آن را در Secrets با نام `ANDROID_KEYSTORE_B64` بگذارید؛ وگرنه هر بار کلید جدید ساخته می‌شود و نسخهٔ جدید روی قبلی نصب نمی‌شود (باید حذف و دوباره نصب شود).

## محدودیت‌ها / نکات
- مرحلهٔ «اسکن IP تمیز کلودفلر» (فاز ۲ ویندوز) هنوز منتقل نشده است.
- فقط IPv4 از تونل رد می‌شود. ترافیک QUIC (UDP/443) عمداً بسته است تا برنامه‌ها سریع به TCP برگردند.
- اولین ساخت ممکن است نیاز به یک دور اصلاح داشته باشد (نتوانستم APK را روی گوشی/شبیه‌ساز اینجا اجرا کنم). متن خطا یا «گزارش» برنامه را بفرستید.

## پروکسی تلگرام (Worker شخصی)
تنظیمات ← «پروکسی تلگرام (Worker شخصی)»: توکن Cloudflare (قالب Edit Cloudflare Workers با Zone Resources = All zones) را وارد کنید، «بارگیری دامنه‌های من» را بزنید، دامنهٔ اصلی خودتان و یک نام فرعی (مثلاً tg) را انتخاب و «ساخت» را بزنید. لینک `https://t.me/webproxy?...` ساخته می‌شود (کپی/باز کردن). Worker متن‌باز ToiCF همراه برنامه نیست و هنگام ساخت دانلود می‌شود. توکن ذخیره نمی‌شود. اگر آدرس workers.dev در شبکهٔ شما فیلتر است، باید دامنهٔ اصلی روی Cloudflare داشته باشید.
